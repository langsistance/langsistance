```
本站为企业官方网站及在线信息查询工具，面向企业研发人员、跨境电商从业者及专利从业人员，
```

### 长版（备注框够大、或管局要求详述）

```
本网站（copiioai.com）为北京酷彼智能科技有限公司的企业官方网站及在线工具平台。

主要功能：面向企业研发人员、跨境电商从业者及专利从业人员，提供
（一）专利文献检索与查询，数据来源为各国专利主管机关公开的专利文献；
（二）专利技术信息比对与侵权风险信息查询；
（三）专利审查历史信息查询；
（四）根据用户提交的查询需求生成相应分析报告。

网站内容与数据均来源于各国专利主管机关公开的专利文献，不含用户生成内容（UGC），
不提供新闻资讯、论坛社区、音视频直播、网络出版、在线交易等服务，
不涉及金融、医疗、药品、教育、文化、广播电影电视节目等需前置审批的领域。
```

### 写法要点

管局靠备注判断「有没有踩前置审批」，所以结构是**先具体写清功能、再明确排除敏感类别**。
空泛的「提供互联网信息服务」反而容易被退回。

- **要写**：具体功能 + 数据来源（公开专利文献，可信度加分）
- **要排除**：新闻 / 论坛 / 直播 / 电商交易 / 网络出版 / 金融 / 医疗 / 教育 —— 这些都要前置审批

## 三点提醒

**1. 域名规格（微信侧）**
「不支持配置父域名，使用子域名」—— 小程序后台**服务器域名要填具体子域名**（如 `mini.copiioai.com`），
不是 `copiioai.com`。另：https 域名**配了端口就只能请求该端口**，不配端口则请求 URL 里也不能带端口。

**2. ⚠️ 生成式 AI 是另一条监管线**
站内的 AI 问答/生成能力，按《生成式人工智能服务管理暂行办法》**可能另需大模型算法备案**。
与 ICP 备案是**两件事**，ICP 过了不等于齐了。需单独确认本服务形态触发到哪一档。

**3. 备案通过前，体验版仍可临时验证**
手机上打开体验版 → 右上角「⋯」→「开发调试」→ 开启后微信判定为调试环境，**跳过域名校验**。
但**正式版无任何绕过手段** —— 所以备案仍是关键路径，不要靠它长期替代。
