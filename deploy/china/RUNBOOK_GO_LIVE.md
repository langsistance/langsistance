# 运行手册：上线编排（Go-Live Run Order）

> 配套总方案：`MIGRATION_PLAN.md`；数据迁移细版：`RUNBOOK_DB_MIGRATION.md`
> 原则：**上线顺序由数据依赖决定，每步有验证与回滚，回滚一律逆序。**

## 1. 上线依赖链（为什么是这个顺序）

```
小程序正式可用 ⟸ 微信登录(P3) ⟸ 国内实例(P1) ⟸ 数据主迁移+双端切流(P2/RUNBOOK)
                                                   ⟸ 备案域名 + AppID(P0)
P2 必须先于一切"写"上线：否则小程序先写国内库、web 后切 → 双主分裂窗口
P3 登录可先于 P2 联调（读美国库验证），但"正式放开注册"必须 P2 之后
```

## 2. 完整上线序列（Gate: 每步绿了才走下一步）

| # | 阶段 | 动作 | 验证（出口标准） | 回滚 |
|---|---|---|---|---|
| L1 | P0 资源 | 备案号下发；AppID 到手；腾讯云机器 IP 给我 | 三样齐 | — |
| L2 | P1 中国实例 | 同构部署 + deepseek 模型模板 + 出站代理 + 冒烟四条 | 冒烟全绿（model-config §4） | 机器未接流量，随意重来 |
| L3 | P2 数据迁移 | 按 `RUNBOOK_DB_MIGRATION.md` §2 执行：备份→传输→导入→校验→**双端同窗切流**→观测 | 校验全绿；双端写同一国内库；15min 零报错 | 整窗回滚（手册 §6） |
| L4 | P3 微信登录 | 部署 W3 代码到中国实例；填 AppID/Secret；开发者工具真机登录 | `/auth/wechat` 返回 token；users 出现 oauth_provider='wechat' 行 | 仅新增端点，关停即回滚 |
| L5 | 小程序体验版 | Taro 上传 → 体验版（内部名单 5-10 人） | 登录/提问/结果面板/落库全链路 OK | 体验版可随时下架 |
| L6 | P4 美国性能决策 | 3 天探针 → 闸门三选一（直连/ProxySQL/从库） | 决策记录 + 实施 | 配置级回滚 |
| L7 | 小程序提审 | 提交审核（类目：工具-信息查询；隐私政策随包） | 审核通过 | 撤回申请 |
| L8 | 全量发布 | 小程序发布；监控看板就绪 | 线上错误率 < 阈值 | 小程序可紧急下架 |

## 3. 小程序发布内部灰度细则（L5/L8）

| 步骤 | 动作 | 验证 |
|---|---|---|
| 3.1 | 体验版成员：开发者工具「成员管理」加 5-10 个内部微信号 | 各自真机可登录 |
| 3.2 | 冒烟用例（体验版固定清单）：新微信用户注册 → 提问 → 面板 17 条级落库 → 历史会话回看 | 全过 |
| 3.3 | **老用户兼容抽验**：用 web 注册过的邮箱账号关联主体（二期绑定前先验：同一手机号/邮箱是否可识别） | 记录结论 |
| 3.4 | 提审材料：类目截图、隐私政策（含数据存储地域声明）、截图 5 张 | 无驳回项 |
| 3.5 | 全量发布后 48h：监控注册/提问/错误率；异常即「暂停服务」按钮 | 数据正常 |

## 4. 双端一致性抽验（L3 后、L8 前持续）

| 抽验 | 方法 |
|---|---|
| 同一 user_id 跨端会话 | web 提问后，小程序会话列表可见同一会话（反之亦然） |
| users 单库唯一 | `SELECT COUNT(*) FROM users` 双端读同一数值；注册新号后双端立即可见 |
| 增长口径 | 小程序注册次日出现在 `注册登录活跃日表`（auth:wechat 列） |

## 5. 监控与值班（L3 后 7 天重点期）

| 监控项 | 来源 | 阈值 |
|---|---|---|
| DB 错误率 | 双端 backend.log 过滤 `pymysql\|OperationalError\|DBAPI` | 0 |
| 美国→国内延迟 | 探针 p95 | 见 P4 判据 |
| 小程序错误 | 微信公众平台「运维中心」错误告警 | 5xx < 1% |
| 注册/登录 | analytics.log auth:wechat/signup 日计数 | 无异常陡降 |
| 落库链路 | query_stream 后 conversations 表行数增长 | 每小时抽查 |

## 6. 回滚矩阵（总表）

| 故障 | 触发点 | 回滚动作 | 数据影响 | 时间 |
|---|---|---|---|---|
| 数据迁移问题 | L3 校验/观测 | RUNBOOK §6 整窗回滚 | 窗口内新数据丢失(留档) | <30min |
| 登录不可用 | L4 | 停 `/auth/wechat` 路由；web/Firebase 不受影响 | 无 | 即时 |
| 小程序体验差/崩溃 | L5/L8 | 体验版下架 / 小程序「暂停服务」 | 无（数据在库） | 即时 |
| 美国 web 慢/错误 | L6 观测 | .env 指回美国旧库(7 天内) 或 ProxySQL 方案加速 | 回滚窗口内 web 新增数据留档 | <30min |
| 模型质量问题 | 任意时 | config.ini [MAIN]/[MODEL] 改回 openrouter（美国）或换模型（中国） | 无 | 即时 |
